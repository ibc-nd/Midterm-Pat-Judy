5a) Pairwise alignment is a method that compares two sequences against each other and aligns them by
inserting gaps and matching residues using "-". You should use pairwise alignment if you want to find
the degree of similarity between two specific sequences. Profile-based searching is a method that
builds a statistical profile from a multiple sequence alignment of an entire protein family. This is
useful when you want to search entire proteomes or genomic databases for members of a conserved
protein family. 

5b) Building an HMM profile from multiple sequences is more sensitive than using a single seqeunce as
a BLAST query because a HMM profile indicates position-specific conservation and shows insertion and
deletion probabilities across an entire protein family. This allows for detection of distant homologs
that have diverged too much in a sequence identity for a single search, such as BLAST, to recognize.

5a) Pairwise alignment compares two sequences and evaluates the conservation between the set by
using dashes to suggest differences, such as insertions or deletions. Pairwise alignment is used
when you only want to compare two sequences. For instance, comparing an unknown sequence to a 
known reference sequence, or comparing the variation between two mutant strains. Profile searching 
converts multiple sequences alignments to a profile, which then is compared to a database. It can
provide the probability of a match being true.Profile searching is used when you want to compare
multiple sequences and identify a pattern or homology.
